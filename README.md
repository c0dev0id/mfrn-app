# MFRN Android App

This app is a companion app for the MFRN Forum (https://motorradfreunde-rheinneckar.de).

It is not a full replacement for the Forum (yet).

Phase 1:
- App Scaffold and implementation of the Login
- Discovery: Learning about the structure / api of the website
- Discussion about what features to build (first UI idea)

Phase 2:
- Planning the implementation of features
  - Already known and wanted: 
    - Kalender view and notifications with upcoming events (date, event name, author, description, participants)
    - Private Messages (sender, receiver/s, messenger style interface, attachment support)
    - Filebase Support (List of Files, Author, Description, GPX File preview on map + download)
- Implement the UI layout, so we have the structure and can then fill in the stubs

Phase 3...N:
  - Feature implementation, one phase per feature
